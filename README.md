📚 DF_bibliotecaLC
Proyecto académico desarrollado en Java como parte del ciclo de Desarrollo de 
Aplicaciones Multiplataforma (DAM).

🚀 Tecnologías utilizadas
- Java
- Maven
  
📋 Funcionalidades
- Gestión de información bibliográfica
- Interfaz gráfica
- Organización del proyecto mediante diferentes clases y componentes

👥 Trabajo en equipo
Proyecto desarrollado en colaboración con otra estudiante como parte de las actividades 
académicas del ciclo.
